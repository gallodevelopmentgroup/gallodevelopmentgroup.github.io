# Gallo Development Group website

Five static pages. No build tools, accounts, or dependencies needed.

## Publish on GitHub Pages
1. Unzip this package.
2. Upload the contents of this folder to the root of a GitHub repository. Keep `index.html`, the other HTML files, and `assets` at the same level. Include `.nojekyll` if uploading with Git.
3. In the repository, open Settings → Pages. Select Deploy from a branch, choose your branch and / (root), then Save.
4. Open the Pages URL shown by GitHub when deployment completes.

Relative links work on both username.github.io and username.github.io/repository/.

Edit the HTML files to change text, assets/style.css for design, and assets/site.js for the menu and request desk. The request desk runs entirely in the visitor’s browser; nothing is collected or sent.
